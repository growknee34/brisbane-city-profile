# City profile of Greater Brisbane

Interactive presentation for GEOM30014 Integrating Digital Infrastructure, Major Assignment, Group 2 (Elvis Lin, Phuc Hung Nguyen, Eliza Wu, Yanfei Zhang).

**Open it:** https://growknee34.github.io/brisbane-city-profile/

## Presenting

| Key | Action |
|---|---|
| → or Space | Next step (a clicker also works) |
| ← | Previous step |
| F | Full screen |
| E | Jump to the map explorer |
| 1–7, 0 | In the map explorer: switch indicator, or 0 for the worst-quarter overlap |

Hover any SA2 on a map to see its value. The map explorer's search box finds any of the 246 Greater Brisbane SA2s.

## Data

- `sa2.json`: simplified ASGS Edition 3 SA2 boundaries for Greater Brisbane (ABS 2021) with the seven indicator values, taken from the `g2_results` layers on the Group 2 GeoServer on 5 November 2026. It is a snapshot; it does not update when the GeoServer layers change.
- Indicator data sources: Groups 1, 2 and 4 (ABS 2021 Census, ABS Estimating Homelessness 2021) and the teaching team (OpenStreetMap).
